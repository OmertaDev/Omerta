Escrow conservation is `total_cash = escrow_cash + paid_cash + refunded_cash + burned_cash`. `employmentCashInvariant(client)` compares remaining reserve against its canonical transfer and death ledger rows in the caller's consistent snapshot. A living original employer refunds unused/expired reserve; assigned jobs cannot cancel before expiry. Canonical estate rules burn street wealth (`social/estate.js` cash sink, open loan-offer escrow precedent), so `voidEmploymentAtDeath(client,h,victim)` closes jobs and writes the negative cash sink. The heir inherits replayable metadata/receipts, never this unused reserve. Worker death cannot redirect an unpaid wage to a different generation. No orphan bucket is intended: shared integration must actually invoke the exported death hook and include escrow and reason vocabulary in canonical invariants before release.
