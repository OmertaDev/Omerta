# Scoped original loan lifecycles

Run `node test/rc1-loan-lifecycle-journal.js`, then from a clean committed checkout with an explicit local PostgreSQL administrative endpoint in `RC1_RESOURCE_DATABASE_URL` run:

```
node test/rc1-native-loan-lifecycles.js --postgres
```

The runner creates and retains a unique database and new restricted temporary output. `--output=PATH` selects a new external private directory; `--seed=VALUE` records a different deterministic stream. The full source identity is checked before execution and again when evidence seals. Installed dependencies are the shared local runtime, not independently attested.

The shared native worker loader executes every original local callback through 77 logical hours using the same application and SQL clocks. Loan offer expiry stays 48 hours; an accepted one-hour loan retains the original additional 24-hour collateral grace; a funded Wanted mark retains its original 72-hour pursuit period. Strict boundary equality and the next due sweep are checked. This is original-duration logical-clock coverage, not literal wall-time, production timing equivalence or a matrix qualification.

Four initial NPC actors use the canonical boss-band spawn primitive and its existing car marks fixture seam. Initial hospital protection through hour80 prevents the canonical Wanted hunt from killing this scoped proof's debtors. The initial street-tax pool contains an explicitly declared100000 cash fixture. NPC population activity is disabled by its normal deployment flag; the remaining original local callbacks still run. Fixture acquisition, funding and survival are not natural-entry proof. No post-baseline balances, statuses, deadlines, outcomes or singleton controls are rewritten.

Every declared loan action and original loan, bounty, Wanted-hunt and buyback job receives a complete restricted snapshot journal. Exact cash equations cover characters, open offers per lender, HOUSE bounty escrow per target, street tax, loan-house vig and the redemption-window destination. Per-car pledge, repayment release and grace forfeiture retain exact owners and cleared flags, tied to unchanged loan identities and deadlines. The classifier independently requires the original expiry/grace to have elapsed, and corruption controls reject a wrong lender or Wanted target. Journals describe the committed aggregate of a job, not each internal transaction's commit order. Other resource categories remain unproved.

Fault triggers abort the canonical terminal writes for Wanted funding, collateral forfeiture, expired offer refunds, Wanted expiry refunds and square-name payment. The same authoritative balances, pledge owners and receipts must survive each abort; the next original worker tick retries without a deadline rewrite. Repeated terminal sweeps and refusals must move no value. Full canonical ledger invariants must pass; no initial drift is subtracted or accepted as a pass. Any failed execution and its source identity remain retained. HTTP/idempotency middleware, concurrent execution, OMR collateral, unshielded combat, other escrow variants, deployment and full release readiness stay OPEN.
