## Release findings

- **R1, release blocker.** The source checks rejected the changed package scripts, Codex and native enterprise inputs. Earlier changes to age and privacy on main also diverged from the reviewed revision. The source transfer verifies whole-file identities before reconstructing the predecessor. The native proof uses the physical application source. The final hosted runs are linked from the PR.
- **R2, native test isolation.** The enterprise runner inherited environment variables supplied to its parent. The new bond manifest variables could select an external deployment during an isolated test. The native admission guard rejects these inputs before starting a proof. The regression covers both profiles and case variants.
- **R3, native catalog compatibility.** Both hosted core jobs rejected the additional `store_payments.revenue_split` column. A real PostgreSQL 18.4 reproduction identified its fresh-install ordinal as 6 and its upgrade ordinal as 9. The correction at `3785994c91797a68c6bbc8673d56f314651858e5` independently compiles the nullable JSONB column, verifies every metadata field and the three adjacent fresh-install ordinals, then reconstructs the original catalog for its existing assertions. Missing, duplicate and mutated metadata are rejected. The full definitions, lot-boundary and Director migration suites passed with their original child deadlines. The Director run covered 120 optional tables, 957 constraints, 23,763 causal controls and 35 transactional DDL rereads.
- **R4, historical fixture compatibility.** The hosted RC1 harness rejected the reviewed Store source after the full application suite passed. Its fixture now recognizes four explicit receipt modules through their complete reviewed current and predecessor identities, and selects the independently frozen historical bodies. The full RC1 harness passed with 164 positive source controls and 602 rejection controls. The additional coverage includes 16 positives and 49 tamper or domain refusals.
- **R5, browser verification.** The hosted portrait test saw two consented avatars in one render and counted zero after the panel repainted. It now captures the image sources from the enabled portrait in a single browser observation and compares them with the two identities in the server's consent response. The focused browser test passed, including download, consent and account isolation. The public UI test also passed through the settled Noir onboarding, mobile check-in and keyboard sign-out controls. The cold landing measured 707 KB against its 768 KB budget.
- **R6, repository census.** The previous hosted application suite stopped because `SPEC.md` listed 950 test files while its candidate contained 952. On the new merge, the recursive inventory counted 972 test files and 597 backend modules. The existing documentation and mounted-route assertions passed against the updated figures.
