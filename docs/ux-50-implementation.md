## Verification

`npm run test:ux` checks confirmed deltas, failures, heir boundaries, escaping,
preferences, and Circle disclosure boundaries. `npm run test:ux:browser` exercises
goals, actual controls, account isolation, late responses, keyboard behavior,
phone sizing, and the integrated real app with disposable data.

Existing client wiring, public start, Path, current-copy, Circle, home, cooldown,
PWA, and engagement checks cover the touched contracts. New static modules use
the normal allowlist and network-first PWA path. Existing reads feed the modules;
progression does not add repeated post-action board fan-out.

Desktop retains the existing rails and sheet. Phone controls move with their
terms and retain their original handlers. Dialogs keep keyboard focus. Quiet
feedback and reduced motion suppress animation. Only deliberate user clicks
send congratulatory messages.
