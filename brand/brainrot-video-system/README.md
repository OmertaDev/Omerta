The packages contain **18 generated base-shot specifications, 18 first-frame prompts, 9 alternate-opening prompts plus their first frames, 4 character-reference prompts, and 65 timed editorial beats**. Each film includes an exact voice script, sound/motion plan, caption text, asset checklist, generation settings and three inexpensive opening-only variants. The six base shots per film are generated as five-second plates and edited into shorter beats.

**These are launch advertisements for the full live game.** All three use present-tense product behavior. The development labels, locked financial room and prototype inset are removed. The fact matrix preserves the actual inspected repository status. Availability, funded market deployment, seasonal game integration and adviser integration at publication are explicit production assumptions—not claims that the current checkout has already shipped.

No tokenomics values or investment returns are invented. No actual betrayal is inferred from a public disclosure. No fictional market price reaction or automatic crafting-to-token bridge is implied.
