omerta-contracts/src/genesis-auction/vendor/cca/TickStorage.sol:42 rejects
prices for which priceQ96 % TICK_SPACING_Q96 != 0. For example, a 5000 minimum
with spacing 2 produces an odd reciprocal and fails simulation. No transaction
is prepared by the backend when simulation fails, so the observed harm is
unavailable bids rather than payment loss.

bid preparation explicitly rejects off-grid prices before simulation. Test
test/genesisauction.js verifies the pinned getter/output and rejects 1001 for
spacing 2. Root owns the UI correction: retrieve verified spacing then round
maximum price downward, preserving the user's minimum accepted OMR rate.
